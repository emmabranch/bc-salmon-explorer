# Raw data

Not stored in this repo because of file size. To reproduce:

1. Download `2_nuseds_cuid_streamid_2026-02-20.csv` (v4) from
   Zenodo: https://doi.org/10.5281/zenodo.19959144
2. Download `METADATA_2_nuseds_cuid_streamid.csv` from
   https://github.com/salmonwatersheds/population-indicators
3. Save both files in this folder.

Source: Carturan, B. & Peacock, S. (2026). Cleaned spawner survey
data (v4). Pacific Salmon Foundation. Zenodo.
https://doi.org/10.5281/zenodo.19959144. Licence: CC BY 4.0.
Derived from Fisheries and Oceans Canada NuSEDS.
